Hey! Thanks for attending the talk, or for finding your way here from the slides.

This is a live example of the newsletter system we built together. Everything you see here (the Gmail-style UI, the MDX content, the React Email templates, the Resend integration) is running in production.

## Talk Resources

The slides and source code are open source. Fork it, break it, make it yours.

- **[Slides and Demo](https://react-mdx-newsletter.cesalberca.com)**: the presentation you just watched, fully interactive
- **[GitHub Repo](https://github.com/cesalberca/react-mdx-newsletter)**: all the code from the talk

## The Stack

Everything we covered, with links to the official docs:

- **[Next.js](https://nextjs.org)**: the React framework powering the app and the preview server
- **[MDX](https://mdxjs.com)**: Markdown + JSX for writing newsletter content
- **[React Email](https://react.email)**: email-safe React components that compile to HTML tables
- **[Resend](https://resend.com)**: modern email delivery API with audience management built in
- **[Tailwind CSS](https://tailwindcss.com)**: utility classes, converted to inline styles by `<Tailwind>` at render time

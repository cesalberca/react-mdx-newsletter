Email HTML is notoriously painful — inline styles, table layouts, and quirks across dozens of clients. React Email abstracts all of that away with a set of battle-tested components.

Here's a minimal newsletter template:

```tsx
import { Html, Head, Body, Container, Text, Hr } from "@react-email/components"

export default function NewsletterEmail() {
  return (
    <Html>
      <Head />
      <Body style={{ backgroundColor: "#f6f9fc", fontFamily: "sans-serif" }}>
        <Container style={{ maxWidth: 600, margin: "0 auto", padding: 20 }}>
          <Text style={{ fontSize: 24, fontWeight: "bold" }}>
            Issue #3: Email Templates
          </Text>
          <Hr />
          <Text>Your newsletter content goes here...</Text>
        </Container>
      </Body>
    </Html>
  )
}
```

The `render()` function from **@react-email/render** converts this JSX into email-safe HTML with all the right inline styles. Preview your templates locally with `npx email dev` before sending them to real inboxes. Next up: actually sending these emails with the Resend API.

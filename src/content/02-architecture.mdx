## The MDX → Email Pipeline

Step by step, here's what happens when you hit "send":

1. **Read** the `.mdx` file from disk
2. **Parse** MDX into an AST (Abstract Syntax Tree)
3. **Transform** — apply rehype/remark plugins (syntax highlighting, etc.)
4. **Render** — React Email components produce email-safe HTML
5. **Inline** — CSS gets inlined (email clients hate `<style>` tags)
6. **Send** — Resend API delivers the email

```tsx
import { render } from '@react-email/render'
import { Resend } from 'resend'
import { WeeklyEmail } from './templates/weekly'

const resend = new Resend(process.env.RESEND_API_KEY)
const html = await render(<WeeklyEmail issue={latestIssue} />)

await resend.emails.send({
  from: 'newsletter@yourdomain.com',
  to: subscribers,
  subject: latestIssue.subject,
  html,
})
```

## React Email Components

React Email gives you email-safe primitives:

```tsx
import {
  Html, Head, Body, Container,
  Section, Text, Button, Img, Hr,
  Preview, Heading, Link,
} from '@react-email/components'

export function WeeklyEmail({ issue }) {
  return (
    <Html>
      <Head />
      <Preview>{issue.preview}</Preview>
      <Body style={main}>
        <Container style={container}>
          <Heading style={h1}>{issue.title}</Heading>
          <Text style={text}>{issue.content}</Text>
          <Button style={button} href={issue.url}>
            Read More
          </Button>
        </Container>
      </Body>
    </Html>
  )
}
```

These components compile down to battle-tested HTML tables and inline styles. No CSS grid. No flexbox. Just like the old days.

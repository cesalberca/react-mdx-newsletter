## The Newsletter Pipeline

```md
  ┌─────────────────────┐
  │   content/{slug}/   │
  │      en.mdx         │  ← Write your newsletter here
  └──────────┬──────────┘
             │ fs.readFileSync + evaluateSync
             ▼
  ┌─────────────────────┐
  │ NewsletterEmail     │
  │    Loader           │  ← Turns MDX into React
  └──────────┬──────────┘
             │
             ▼
  ┌─────────────────────┐
  │ NewsletterTemplate  │
  │  └─ EmailTemplate   │  ← React Email layout
  │     └─ <Html>...    │
  └──────────┬──────────┘
             │ render()
             ▼
  ┌─────────────────────┐
  │    HTML string      │  ← Email-safe HTML + inline styles
  └──────────┬──────────┘
             │ resend.emails.send()
             ▼
  ┌─────────────────────┐
  │       Resend        │  ← Delivery & analytics
  └──────────┬──────────┘
             │
             ▼
         📬 Inbox
```

## Project Structure

```txt
src/newsletter/
├── api/
│   ├── subscribe.ts          # Subscribe logic (sign token, send confirmation)
│   ├── confirm.ts            # Confirm logic (verify token, add contact)
│   └── broadcast.ts          # Broadcast logic (render MDX, send to audience)
├── components/
│   ├── email-button.tsx      # CTA button for emails
│   └── newsletter-email-loader.tsx  # Reads MDX, wraps in template
├── content/
│   └── {slug}/en.mdx         # Newsletter content per issue
├── emails/
│   ├── newsletter/           # One .tsx per issue (thin wrappers)
│   └── transactional/        # Confirmation & welcome emails
├── mdx/
│   ├── email/                # MDX components for email rendering
│   └── web/                  # MDX components for web rendering
├── templates/
│   ├── email-template.tsx    # Base email layout
│   └── newsletter-template.tsx  # Newsletter-specific layout
└── domain/
    └── newsletter-metadata.ts
```

## Creating a new issue

1. Create a new issue in `/newsletter/content/{slug}/en.mdx`
2. Create an email in `/newsletter/emails/{slug}.tsx`
3. Push to `main`

## Required Environment Variables

```bash
# Resend — email delivery
RESEND_API_KEY=re_...          # Your Resend API key
RESEND_EMAIL_FROM=you@domain.com  # Verified sender address
RESEND_AUDIENCE_ID=...         # Audience ID from Resend dashboard
RESEND_TEST_EMAIL=you@domain.com  # Address for test sends

# Auth
JWT_SECRET=...                 # Secret for signing confirmation tokens

# Broadcast protection
NEWSLETTER_BROADCAST_TOKEN=... # Bearer token for the broadcast endpoint

# App
NEXT_PUBLIC_URL=https://yourdomain.com  # Public URL (used in email links)
```

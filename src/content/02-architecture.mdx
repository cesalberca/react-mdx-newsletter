## The newsletter architecture

Step by step, here's what happens when you hit "send":

1. Create an MDX content under content
2. Create an email in /emails/2026-045.tsx
3. Load using newsletter-email-loader
4. Use NewsletterTemplate, underneath uses EmailTemplate

## React Email Components

React Email gives you email-safe primitives:

```tsx
import {
  Html, Head, Body, Container,
  Section, Text, EmailButton, Img, Hr,
  Preview, Heading, EmailLink,
} from '@react-email/components'

export function WeeklyEmail({ issue }) {
  return (
    <Html>
      <Head />
      <Preview>{issue.preview}</Preview>
      <Body style={main}>
        <Container style={container}>
          <Heading style={h1}>{issue.title}</Heading>
          <Text style={text}>{issue.content}</Text>
          <Button style={button} href={issue.url}>
            Read More
          </Button>
        </Container>
      </Body>
    </Html>
  )
}
```

These components compile to HTML tables and inline styles.

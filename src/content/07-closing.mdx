# My Newsletter + Thank You

Hey everyone,

Thanks for sticking through this totally-not-a-scam presentation about building newsletters with MDX, React Email, and Resend.

## Quick Recap

1. **MDX**: Write content in Markdown, use React components when needed
2. **React Email**: Email-safe components that compile to battle-tested HTML
3. **Resend**: Modern email delivery API with great DX
4. **CI/CD**: Automate the entire pipeline with GitHub Actions
5. **Gotchas**: SPF/DKIM, 102KB limit, Outlook, unsubscribe compliance

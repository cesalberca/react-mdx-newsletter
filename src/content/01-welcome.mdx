## What Is a Newsletter, Really?

At its core, a newsletter is just:

1. **Content** — written in some format (Markdown, HTML, MDX)
2. **Rendering** — turned into email-safe HTML
3. **Delivery** — sent via an email service provider
4. **Tracking** — opens, clicks, bounces

## Why MDX?

MDX = **Markdown** + **JSX**. Write content naturally, drop in React components when you need them.

```mdx
# Welcome to the newsletter

Here's a normal paragraph.

<SubscribeButton plan="premium" />

And back to normal text.
```

### Benefits for newsletters:

- **Familiar syntax** — your team already knows Markdown
- **Component reuse** — buttons, callouts, code blocks
- **Type safety** — props are checked at build time
- **Preview on web** — same components render on your site AND in emails

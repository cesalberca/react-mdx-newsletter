## Violation #2: The `<div>` Disaster

Email clients handle `<div>` inconsistently. Some respect dimensions, others don't.

**The fix:** Use `<table>` with `<tr>` and `<td>` for layout.

```tsx
// WRONG - will break
<div style={{ display: 'flex', gap: '16px' }}>
  <div style={{ flex: 1 }}>Column 1</div>
  <div style={{ flex: 1 }}>Column 2</div>
</div>

// RIGHT - works everywhere
<Section>
  <Row>
    <Column className="w-1/2">Column 1</Column>
    <Column className="w-1/2">Column 2</Column>
  </Row>
</Section>
```

React Email's `<Row>` and `<Column>` components handle this for you.

## Violation #3: Image Crimes

Common image mistakes in email:

1. **No `width` and `height` attributes** — images will be displayed at full size
2. **Relative URLs** — email clients can't resolve them
3. **SVG** — not supported in most email clients
4. **Background images** — Outlook ignores CSS `background-image`

```tsx
// BAD
<img src="/logo.png" />

// GOOD
<Img
  src="https://yourdomain.com/logo.png"
  width={200}
  height={50}
  alt="Company Logo"
/>
```

> Pro tip: create an utility function `emailImageBaseUrl` that adds the domain
> ```typescript
> const BASE_URL = process.env.NEXT_PUBLIC_URL ?? "http://localhost:3000";
>
> export function emailImageBaseUrl(filename: string): string {
>   return `${BASE_URL}/email-static/${filename}`;
> }
> ```

### Dark Mode Gotcha

Some email clients invert colors in dark mode. Your white logo on a transparent background? Now it's invisible on a white-turned-dark background.

**Fix:** Always add a background color, padding or same color as the background shadow in logos.

## Violation #4: Font Crimes

Email font support is limited:

**Safe fonts:**
- Arial, Helvetica
- Georgia, Times New Roman
- Courier New
- Verdana, Trebuchet MS

**Unsafe:**
- Google Fonts (partially supported, fallback required)
- System fonts (`-apple-system`, etc.)
- Any `@font-face` import

```tsx
// React Email approach - always provide fallback
<Text style={{
  fontFamily: "'Georgia', 'Times New Roman', serif",
  fontSize: '16px',
  lineHeight: '1.5',
}}>
  Your newsletter content here.
</Text>
```

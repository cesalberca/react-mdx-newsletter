  ## The Email Rendering Problem

  Unlike web browsers, email clients are **stuck literally in 2003**:

  - **Gmail** (Custom engine) — Partial CSS support, strips `
  <style>` tags, no media queries in some contexts
    - **Outlook** (Word engine) — Yes, **Microsoft Word** renders your HTML
    - **Apple Mail** (WebKit) — Actually decent
    - **Yahoo** (Custom) — Surprisingly okay
    - **Outlook.com** (Custom) — Different from desktop Outlook

  ## What Works in Email

  **Safe to use:**
  - Inline styles (`style="..."`)
  - Tables for layout (yes, _really_)
  - Basic CSS: `color`, `font-size`, `padding`, `margin`, `background-color`
  - `<img>` with absolute URLs
  - `<a>` tags with `href`

    **Danger zone:**
    - `
    <div>` with flexbox or grid — Gmail will ignore most properties.
      - `position: absolute/fixed` — ❌
      - `box-shadow` — ❌
      - CSS variables — ❌
      - `@media` queries — limited support
      - External stylesheets — stripped by Gmail
      - JavaScript — obviously not

  ## How React Email Helps

  React Email abstracts away _some_ of the pain. You write modern JSX, it outputs legacy-compatible HTML:

  ```tsx
  // You write this:
  <Tailwind>
    <Body className="bg-white font-sans">
      <Container className="mx-auto max-w-xl px-4 py-8">
        <Section className="p-5">
          <Text className="text-base text-[#333]">
            Hello subscriber!
          </Text>
          <Button
            href="https://example.com"
            className="bg-blue-600 text-white px-6 py-3 rounded"
          >
            Click me
          </Button>
        </Section>
      </Container>
    </Body>
  </Tailwind>

  ```html
  <!-- It outputs this: -->
  <table width="100%" cellpadding="0" cellspacing="0">
    <tr>
      <td style="padding:20px">
        <p style="font-size:16px;color:#333">
          Hello subscriber!
        </p>
        <table cellpadding="0" cellspacing="0">
          <tr>
            <td style="background-color:#007bff;padding:12px 24px">
              <a href="https://example.com"
                 style="color:#fff;text-decoration:none">
                Click me
              </a>
            </td>
          </tr>
        </table>
      </td>
    </tr>
  </table>
  ```

  ## The Email Rendering Problem

  Unlike web browsers, email clients are **stuck literally in 2003**:

  - **Gmail** (Custom engine): Partial CSS support, strips `
  <style>` tags, no media queries in some contexts
    - **Outlook** (Word engine): Yes, **Microsoft Word** renders your HTML
    - **Apple Mail** (WebKit): Actually decent
    - **Yahoo** (Custom): Surprisingly okay
    - **Outlook.com** (Custom): Different from desktop Outlook

  ## What Works in Email

**Safe to use:**
- Inline styles (`style="..."`)
- Tables for layout (yes, _really_)
- Basic CSS: `color`, `font-size`, `padding`, `margin`, `background-color`
- `<img>` with absolute URLs
- `<a>` tags with `href`

**Danger zone:**
- `<div>` with flexbox or grid: Gmail will ignore most properties.
- `position: absolute/fixed`: ❌
- `box-shadow`: ❌
- CSS variables: ❌
- `@media` queries: limited support
- External stylesheets: stripped by Gmail
- JavaScript: **obviously not**. Well, actually [kind of](https://amp.dev/about/email.html)
